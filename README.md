# Wavebox — библиотека игровых звуков

Статический сайт с поиском, 27 категориями, настоящими звуковыми волнами, плеером, скачиванием звуков Opus онлайн и оригинальных WAV локально, избранным и историей прослушивания. Интерфейс на русском языке, работает на компьютере и телефоне.

Каталог: **11 251 звук**, 22,8 часа, 14,8 ГиБ исходных WAV. Источники — 25 ZIP-архивов и `2000 Game Sound FX.unitypackage`. Два `EmbeddedAssetsTextures` содержат PNG и не входят в аудиокаталог. PDF-файлы не импортируются.

## Запустить на компьютере

Откройте `Start Library.cmd` или выполните из корня проекта:

```powershell
python scripts/server.py --open
```

Сайт доступен по адресу http://127.0.0.1:4173. Локальный сервер автоматически подключает папку `audio`. Оригинальные имена файлов сохранены. Сервер поддерживает HTTP Range для перемотки длинных WAV.

## GitHub Pages

В репозитории хранятся интерфейс и каталог метаданных. Все 11 251 звуков онлайн доступны в Opus 80 кбит/с (моно/стерео; многоканальные оригиналы сведены до двух каналов): воспроизводятся сразу и скачиваются по отдельности. Исходные WAV в `audio/` исключены из Git и остаются локально.

Закодированные копии хранятся частями ZIP в GitHub Release `audio-v1`. Workflow скачивает их и включает в Pages. Это позволяет сохранить репозиторий небольшим и уложить полный сайт в лимит 1 ГБ.

1. Подготовьте Opus и загрузите `.local/release/wavebox-audio-*.zip` в GitHub Release с тегом `audio-v1` (для созданного репозитория это уже выполнено).
2. Отправьте проект в GitHub-репозиторий в ветку `main` или `master`.
3. Откройте **Settings → Pages → Source → GitHub Actions**.
4. Workflow `Publish Wavebox to GitHub Pages` соберёт и опубликует сайт. Его можно запустить вручную через **Actions → Run workflow**.

Онлайн-версия работает сразу. Для доступа к исходным WAV нажмите **Подключить файлы** и выберите папку `audio` или папку с распакованными WAV. Файлы сопоставляются по пути, имени и размеру. Они остаются на устройстве, не передаются на сервер, а избранное хранится в браузере. После перезагрузки страницы папку необходимо выбрать снова. Можно подключать отдельные коллекции по очереди.

Чтобы разместить звуки онлайн при наличии необходимых прав, загрузите их на отдельный статический хостинг, сохранив структуру внутри `audio/`, и укажите его HTTPS-адрес в `config.json`:

```json
{"audioBaseUrl": "https://your-audio-host.example/library"}
```

Для принудительного скачивания файлов с другого домена настройте на аудиохостинге `Content-Disposition: attachment`. Локальные подключённые файлы скачиваются прямо из браузера. Условия использования исходных звуков определяются их авторами; публичное размещение аудио требует соответствующих прав.

## Повторный импорт

```powershell
python -m pip install -r requirements.txt
python scripts/import_audio.py --downloads "C:/Users/YOUR_NAME/Downloads"
python scripts/encode_audio.py
```

Импорт обновляет каталог оригиналов; после него запустите кодировщик повторно, чтобы восстановить ссылки на онлайн-копии.

Скрипт безопасно читает WAV из ZIP и Unity package, сохраняет их в `audio/` и обновляет `data/catalog.json`. Содержимое документов не исполняется. Отчёт об импорте находится в `.local/import-report.json`. Если архивы не изменились, исходные WAV не распаковываются повторно.

```powershell
node --check app.js
python scripts/verify_catalog.py
python scripts/export_site.py
```

## Управление

- `/` — перейти к поиску.
- `Пробел` — play / пауза текущего звука.
- `N` — следующий звук в текущей выборке.
- `?` — показать горячие клавиши.
- Поиск понимает исходные английские названия и основные русские запросы: шаги, победа, монета, взрыв, дождь, дверь, металл, голос и другие.

Сборщик и внешний JavaScript не нужны. Основные файлы: `index.html`, `styles.css`, `app.js`, `data/catalog.json`. Все пути относительные, поэтому сайт работает в GitHub Pages с префиксом имени репозитория.
